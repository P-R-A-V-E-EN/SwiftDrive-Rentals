# SwiftDrive-Rentals

A full-stack car rental web application developed as a Software Engineering academic project.

📌 Project Overview

SwiftDrive Rentals is a web-based car rental system designed to make vehicle browsing and booking easier for customers while providing management features for administrators.

The system includes customer registration and login, vehicle browsing, search and filtering, vehicle booking, customer account management, and an admin management area.

🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap
* PHP
* MySQL
* XAMPP
* phpMyAdmin

✨ Key Features

Customer Features

* User registration and login
* Browse available vehicles
* Vehicle categories
* Vehicle search and filtering
* View vehicle details
* Book vehicles
* Manage customer account
* View bookings and booking status

Admin Features

* Admin login
* Manage vehicles
* Manage bookings
* Manage customers
* Manage contact messages

Validation & Database

* JavaScript form validation
* PHP server-side processing
* MySQL database integration
* Booking conflict checking
